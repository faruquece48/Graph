# Graph

Next.js graph plotting workspace. The home, Linear, and ML pages are intentionally empty until graphs are specified.

## Run locally

```powershell
cd C:\Users\Windows 11\Downloads\Graph
npm run dev
```

Open http://localhost:3000.

Add menu entries to `menuItems` in `app/layout.tsx` and create a matching route under `app/`.

## Check

```powershell
npm run lint
npm run build
```
